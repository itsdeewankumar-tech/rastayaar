# RastaYaar SEO and AdSense readiness plan

## Search-intent clusters to target

These are relevant keyword themes, not measured monthly search volumes. Validate volumes, competition and country/device filters in Google Keyword Planner and Google Search Console before prioritising them.

### Core high-intent pages
- Karachi bus routes
- Karachi bus route finder
- Karachi public transport routes
- bus routes in Karachi with stops
- Karachi bus fare / bus fare in Karachi
- Karachi public transport trip planner
- Karachi bus route map

### Route and service pages
- Karachi Red Bus routes / People's Bus Service routes
- Karachi EV bus routes
- Karachi Green Line route and stations
- Karachi Orange Line route
- Karachi minibus routes
- Karachi coach bus routes

### Location + destination pages (only publish when useful and accurate)
- Sultanabad to IoBM / CBM University bus route
- bus from [area] to [landmark]
- buses from [area] to [university/hospital/market]
- buses stopping at [area]

Do not generate thousands of near-identical doorway pages just to target every keyword pair. Each indexable page should have useful, specific information, visible route records, source/update notes and related links.

## Technical SEO checklist
- Use a unique descriptive title and meta description for every indexable route, area and article page.
- Set absolute canonical URLs after the production domain is finalised; do not guess the domain.
- Generate and submit an XML sitemap containing canonical, indexable URLs; keep robots.txt crawlable and reference the sitemap using the real domain.
- Verify the domain in Google Search Console, inspect representative URLs, submit the sitemap and monitor indexing/crawl errors.
- Keep important route details and headings in the rendered page, not only in hidden UI or images.
- Use descriptive internal links between route pages, area pages, fares and helpful articles. Avoid thin or duplicate pages.
- Add meaningful alt text, responsive images, good Core Web Vitals, HTTPS and mobile-friendly forms.
- Use structured data only where it accurately describes visible page content. Do not mark the transport planner as an official operator or invent ratings/reviews.

## AdSense readiness checklist
- Publish and keep accurate the Privacy Policy, About, Contact and route-data disclaimer pages.
- Before enabling ads, update the Privacy Policy to describe the actual analytics, cookies, ad vendors, consent tools and data practices used.
- Ensure there is original, useful content beyond route cards and search forms; clearly explain sources, limitations, fare uncertainty and how users can report corrections.
- Keep navigation and content usable; never encourage ad clicks or disguise ads as route controls.
- Do not place ads on empty search results, error pages or pages that have little useful content. Review Google's current publisher policies and regional consent requirements before launch.
- Approval and earnings are not guaranteed by these changes.

## Data quality and trust
- Label imported/community records as unverified until checked against an operator or credible source.
- Record source, last-checked date, service status and fare validity where possible.
- Provide a correction/report link on route detail pages.
- Do not claim real-time arrivals, exact travel time, live bus locations or guaranteed fare unless a real data source supports it.
